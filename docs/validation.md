# 验证记录

## 0.3.5 自动主唱净化（2026-11-07）

35 项 Node.js 和 129 项 Python 测试通过。新增覆盖同音高重入、正常长音、重复唱词、追踪短抖动、低置信度识别、源音频变更、配置开关、手工规则优先和清晰度 EQ。所有发布测试使用合成数据，不包含实际歌曲、歌词或参考声线。

使用当前真实 DSH SDK 验证原生 `autoSoloGuard` 开关可显示、可关闭，默认独立和声音量为 0，工具正常注册。公开版的路径配置、现有模型文件校验和真实 CPU 识别另外在隔离数据目录验证：一段 20 秒私有测试音轨自动找到 1 处重入残音，无手工规则；切换开关后不应用已有计划。没有向真实 QQ 发送测试消息。

相同算法在本机完整的新合成流程也跑过 20 秒真实 GPU 换声，音高和时长检查通过；自动切点与此前用户验收的手工修正相差 0.01 秒。用户听自动版后确认与修好的效果一致。本机这次检测约 5.4 秒，分析缓存复用约 0.17 秒；公开版隔离 CPU 检测约 2.8 秒。这些是具体样本耗时，不是任意歌曲的延迟保证。

识别不能可靠确认的候选不自动删。该验证不表示所有语言、任意和声或重叠唱词都能完美识别；也没有把私有试听、手工切点或测试歌曲打入发布包。

## 0.3.4 副歌定位修复（2026-11-07）

35 项 Node.js 和 109 项 Python 测试通过。新增覆盖三个独立音频窗口、正负偏移、增益差、不同录音、插入间奏、损坏缓存、音源变更、参考超时、OST 说明和零时长词。测试使用合成音频与虚构文本，发布包不含实际歌曲或歌词。

真实失败请求为《叹云兮》副歌：B 站所选完整音源没有歌词时间轴，本地识别结果有大量零时长词，未找到可靠重复长句；网易云官方标题带电视剧片尾曲说明，又被旧版严格标题匹配误排除。

修复后在不替换选定 B 站音轨的情况下，以网易云原版作对齐参考。三个独立窗口的相关度分别约 0.9990、0.9992、0.9977，偏移均为 0.1605 秒；副歌定位为原音轨约 72.7405–114.6605 秒，共 41.92 秒。首次完整参考查询和定位约 1.56 秒，同音源缓存定位约 0.06 秒；开头到副歌范围也已核对。以上是定位耗时，不含换声合成，没有为验证发送 QQ 歌声。
