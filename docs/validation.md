# 0.2.0 验证记录

交付源码原标记 0.1.0；为接续同仓库既有版本，本次公开包统一标记为 0.2.0。以下实测记录来自交付材料，发布前的回归校验另行执行。

验证日期：2026-11-05。此记录区分实际运行与离线夹具；不表示所有平台的所有歌曲都可播放。

## 已实际验证

- Windows / Python 3.11 新建隔离虚拟环境，安装 PyTorch 2.4.1 + CUDA 12.1 和固定依赖；`pip check` 通过。
- 固定版本 Seed-VC 下载、校验、应用三个源码补丁。模型使用已有本地权重并逐项检查 SHA-256；没有为验收重新下载全部 2.6 GB 模型。
- RTX 2060 SUPER 8 GB：8 秒音频和 104 秒长音轨通过完整分离、转换、音准检查与混音流程。104 秒为私有短素材循环构造的长音轨夹具，未把它称作真实完整商业歌曲。
- 104 秒音轨生成约 179 秒；音高误差中位数约 10.46 cents，90 分位约 36.54 cents。该指标只比较来源与转换结果音高，不证明音色完全一致或伴奏无残留人声。
- 从长音轨缓存的 80 秒位置剪出剩余 24 秒；没有产生新转换任务，也没有重新查找原曲。
- DSH 0.2.1-rc.5 的实际 Cordis / ToolRuntime：注册插件、调用后端、调用已有语音工具、同回合去重、发送权限 guard 生效。发送工具使用隔离 mock，没有发出真实 QQ 消息。
- DSH CLI 在隔离 home/profile 安装本地 `.tgz`，profile bundle 正确包含唱歌插件；未改动日常使用的 profile。

## 离线验证

- Node.js 测试覆盖参数、长音频、当前会话发送、失败不发送、不确定送达不重试、取消与进程启动。
- Python 测试覆盖音源顺序、访问失败不绕过、版本检查、正常播放与试看、整首/起点/副歌选择、歌词次数、本地路径和缓存完整性。
- 副歌及指定歌词缓存剪切使用确定的测试时间轴验证流程；未把这些夹具当作真实歌曲识别准确率。
- QQ 音乐新增适配通过离线结构测试；本机在线搜索测试未取得可用曲目，不能宣称已完成该站完整取音频验收。

## 仍需使用者验收

自己的参考音色听感、真实歌曲副歌定位、目标机器模型下载、QQ 长语音播放，以及当前网络下的音源可用性。平台播放器、媒体目录、文件大小或主机外层超时限制仍可能影响结果。

B 站标题优先选择官方音频、歌词版、录音室或纯享版，降低对白和现场声音混入的机会。标题标签无法证明音轨干净，原曲自带采样、和声或人声分离残留仍需区分；本版本不宣称能自动清除所有其他人声。

## 0.3.0 补充验证（2026-11-06）

- 27 项 Node.js、59 项 Python 测试通过；Python 同时在仅装轻量测试依赖的新环境中通过。
- 实际 DSH SDK 的配置序列化、设置取值和工具注册通过。配置包括参考录音、默认时长、自动八度、三路音量及间奏开关。
- 发布源码在 Windows / RTX 2060 SUPER 上做三次未命中成品缓存的本地转换：低音自动 +12、正常音域 0、关闭自动八度后低音保持 0。三次均通过原曲相对音准检查，其中正常音域样本包含独立和声并通过单独检查。每段实际选取约6秒，生成约29–35秒；不是整首速度承诺。
- 实测将人声/伴奏/和声音量设为1.3/0.4/0.7，工作进程和混音结果均使用该值；关闭间奏处理后保留时间轴。
- KARA2 使用固定模型及参数，实际分离无须下载在线模型列表。主环境与分离环境的安装依赖分别解析通过；没有将两套不兼容的 protobuf 依赖混装。
- 本轮复用已存在的模型和推理依赖，没有重新下载全部模型，也没有在干净电脑上完成完整安装。测试音频、参考音色和私人数据均未进入发布包，没有发送真实 QQ 测试消息。

音准 QA 仍可能拒绝难分离的重叠声部；不宣称所有歌曲都能通过。失败结果不会作为成功歌声发送。

## 0.3.2 补充验证（2026-11-06）

35 项 Node.js 与 85 项 Python 测试通过。新增覆盖完整版意图、禁止片段缓存冒充整首、保留来源版本、源文件与成品哈希、错误阶段透传、超过旧32/64KB边界的结果JSON，以及基础移调为0时仍处理低音句。实际 DSH SDK 的配置解析及插件注册检查通过。

20秒实际双声部 GPU 试听验证：整首基础判断为0时，低音主唱的中位频率从约146.4Hz映射到292.5Hz，已有高音保持原音域；主唱与和声按分句目标的音准检查通过，用户确认试听合适。不是用歌名或固定秒数决定移调。旧版分句记录仍可读取，关闭自动八度保留原调。

从一条失败任务复核：完整音源已下载，但可提取的人声极少；该失败发生在换声前，不是歌长上限。返回的公开错误明确区分阶段，具体本机路径和原始模型日志不进入工具回复。本机已验证可从先前成功的片段记录找到且校验完整原音源，不再为该版本重新联网查找。

本机完成234.08秒整曲结果的复核：主唱误差中位数/90分位约13.17/49.58 cents，和声约13.39/50.27 cents。保留完整母带，确认播放器文件和缓存回读一致，46条录音复查通过。该整曲除分句处理和有界八度纠正外，还对两处短和声做了局部上下文重算；后者是本次维护步骤，不表示公开插件会自动重试所有困难声部。公开流程仍会拒绝最终未通过检查的结果。

真实QQ桥接回读该完整缓存，返回JSON约69.5KB，已超过旧32/64KB截断边界；完整响应解析成功，没有重新GPU合成或调用TTS。接口确认发出的是一条语音消息，源文件234.08秒。未把接口发送成功等同于用户已验收整首听感。
