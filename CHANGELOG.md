# 更新记录 / Changelog

## 0.1.0 — Initial public source release / 首次公开源码

- Local Demucs → Seed-VC → RMVPE → mixed MP3 pipeline. / 本地分离、换声、音高检查与混音流水线。
- QQ `sing_song` integration based on deployed `0.9.10-singing.8`. / 基于已部署版本的 QQ 点歌工具。
- Timestamp and repeated-lyric positioning, public/local sources, finished recording cache, instrumental gap editing and vocal-forward mixing. / 秒数与重复歌词定位、公开/本地音源、成品缓存、间奏裁剪与人声混音。
- Publication copy adds configurable paths, direct reference audio, model revision/checksum locking and bilingual installation, usage and troubleshooting docs. / 发布副本增加路径配置、直接参考音频、模型版本与哈希锁定，以及双语安装、使用和排查文档。
- No credentials, voice samples, songs, model weights or private runtime records are distributed. / 不分发密钥、声音样本、歌曲、模型权重或私人运行记录。
